# Побитовые операции в JavaScript/TypeScript

Побитовые операторы позволяют работать с отдельными битами числа. Это часто используется для хранения и проверки множества флагов в одном числе.

## Основные операторы

| Оператор | Название          | Пример    | Описание                                                                                         |
| -------- | ----------------- | --------- | ------------------------------------------------------------------------------------------------ |
| `&`      | И (AND)           | `a & b`   | Побитовое И: каждый бит результата равен 1, только если оба соответствующих бита равны 1         |
| `\|`     | ИЛИ (OR)          | `a \| b`  | Побитовое ИЛИ: каждый бит результата равен 1, если хотя бы один из соответствующих битов равен 1 |
| `^`      | Исключающее ИЛИ   | `a ^ b`   | Побитовое XOR: каждый бит результата равен 1, если соответствующие биты различны                 |
| `~`      | НЕ (NOT)          | `~a`      | Побитовое отрицание: инвертирует все биты числа                                                  |
| `<<`     | Сдвиг влево       | `a << n`  | Сдвигает биты числа влево на n позиций                                                           |
| `>>`     | Сдвиг вправо      | `a >> n`  | Сдвигает биты числа вправо на n позиций (с сохранением знака)                                    |
| `>>>`    | Беззнаковый сдвиг | `a >>> n` | Сдвигает биты вправо на n позиций (без сохранения знака)                                         |

## Примеры с флагами

```ts
const FLAG_A = 1 << 0; // 0b0001 = 1
const FLAG_B = 1 << 1; // 0b0010 = 2
const FLAG_C = 1 << 2; // 0b0100 = 4

let flags = 0;
flags |= FLAG_A; // Установить флаг A: flags = 0b0001
flags |= FLAG_B; // Установить флаг B: flags = 0b0011
if (flags & FLAG_A) {
  /* Проверить установлен ли флаг A */
}
flags &= ~FLAG_B; // Сбросить флаг B: flags = 0b0001
```

## Детальные примеры операций

### Операция И (&)

```ts
// Проверка конкретных битов
const flags = 0b1101; // 13 (биты: 3,2,0 установлены)
const mask = 0b1100; // 12 (биты: 3,2 установлены)

// Подробный разбор операции &:
// flags = 0b1101
// mask  = 0b1100
// ----------------
// result= 0b1100 = 12

// flags & mask = 0b1101 & 0b1100 = 0b1100 = 12
if (flags & mask) {
  /* Результат НЕ равен 0, значит хотя бы один из битов 2 или 3 установлен */
  console.log("Есть пересечение битов"); // Выполнится
}

// Проверка точного совпадения
if ((flags & mask) === mask) {
  /* Результат равен маске, значит ВСЕ биты из маски установлены */
  console.log("ОБА бита 2 и 3 установлены"); // Выполнится
}

// Дополнительные примеры:
const flags2 = 0b1001; // 9 (биты: 3,0 установлены)
// flags2 & mask = 0b1001 & 0b1100 = 0b1000 = 8
if (flags2 & mask) {
  console.log("Есть пересечение"); // Выполнится (бит 3 общий)
}
if ((flags2 & mask) === mask) {
  console.log("Все биты маски установлены"); // НЕ выполнится (бит 2 отсутствует)
}

const flags3 = 0b0011; // 3 (биты: 1,0 установлены)
// flags3 & mask = 0b0011 & 0b1100 = 0b0000 = 0
if (flags3 & mask) {
  console.log("Есть пересечение"); // НЕ выполнится (нет общих битов)
}

// Практический пример с именованными флагами:
const FILE_READ = 0b001; // 1
const FILE_WRITE = 0b010; // 2
const FILE_EXECUTE = 0b100; // 4

const permissions = FILE_READ | FILE_WRITE | FILE_EXECUTE; // 0b111 = 7
const writeExecuteMask = FILE_WRITE | FILE_EXECUTE; // 0b110 = 6

// Проверяем, есть ли права на запись ИЛИ выполнение
if (permissions & writeExecuteMask) {
  console.log("Есть права на запись или выполнение"); // Выполнится
}

// Проверяем, есть ли права И на запись И на выполнение
if ((permissions & writeExecuteMask) === writeExecuteMask) {
  console.log("Есть права и на запись, и на выполнение"); // Выполнится
}
```

### Операция ИЛИ (|)

```ts
// Установка битов
let flags = 0b0001; // 1
flags |= 0b0010; // Добавляем бит 1: flags = 0b0011 = 3
flags |= 0b1000; // Добавляем бит 3: flags = 0b1011 = 11
```

### Операция НЕ (~) и сброс битов

```ts
// Сброс конкретных битов
let flags = 0b1111; // 15
const mask = 0b0110; // 6

// Сбрасываем биты 1 и 2
flags &= ~mask; // flags = 0b1111 & 0b1001 = 0b1001 = 9
```

## Быстрые маски

- `flags & MASK` — проверить, установлены ли какие-либо биты из MASK
- `(flags & MASK) === MASK` — проверить, установлены ли ВСЕ биты из MASK
- `flags | MASK` — установить биты из MASK
- `flags & ~MASK` — сбросить биты из MASK
- `flags ^ MASK` — инвертировать биты из MASK

## Применение в реактивных системах

Побитовые флаги позволяют эффективно хранить и проверять множество состояний в одном числе:

```ts
enum ReactiveFlags {
  None = 0, // 0b000000
  Mutable = 1 << 0, // 0b000001 = 1
  Watching = 1 << 1, // 0b000010 = 2
  RecursedCheck = 1 << 2, // 0b000100 = 4
  Recursed = 1 << 3, // 0b001000 = 8
  Dirty = 1 << 4, // 0b010000 = 16
  Pending = 1 << 5, // 0b100000 = 32
}

// Примеры использования:
let nodeFlags = ReactiveFlags.Mutable | ReactiveFlags.Watching; // 0b000011 = 3

// Проверки
if (nodeFlags & ReactiveFlags.Mutable) {
  /* Узел мутабельный */
}
if (
  (nodeFlags & (ReactiveFlags.Dirty | ReactiveFlags.Pending)) ===
  ReactiveFlags.Pending
) {
  /* Узел ожидает, но не грязный */
}

// Установка/сброс
nodeFlags |= ReactiveFlags.Dirty; // Пометить как грязный
nodeFlags &= ~ReactiveFlags.Pending; // Убрать флаг ожидания
```

## Преимущества побитовых операций

1. **Производительность**: Побитовые операции выполняются быстрее обычных
2. **Память**: Один number может хранить до 32 boolean-значений
3. **Атомарность**: Все флаги обновляются за одну операцию
4. **Читаемость**: При правильном использовании код становится более выразительным
